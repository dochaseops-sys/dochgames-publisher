# DochGames Publisher Platform

> Streamlined, ad-monetised web game widgets for publishers with little or no technical knowledge. Embed instant HTML5 & WebGL games on your website in under five minutes.

---

## 🌟 Key Capabilities

- **Zero-Friction Website Setup**: Connect your domain with automated URL normalisation.
- **Continuous 3-Step Builder Flow**:
  1. **Choose Template**: Game carousel (Recommended), Featured game, Game grid, or Floating launcher button.
  2. **Customise & Preview**: Real-time side-by-side preview with desktop and mobile viewport toggles, theme switcher (Cloud light / Navy dark), accent colour presets, and interactive playable game test mode.
  3. **Install & Verify**: Single authoritative embed code for WordPress, Shopify, Webflow, Wix, React/Next.js, or custom HTML, plus "Send to Developer" brief generator.
- **Honest Installation Verification**: Real domain-matching checks and actionable diagnostic error messaging without fabricated millisecond latencies, fake TLS certificates, or invented CDN states.
- **Full Lifecycle Management**: Clear status tracking (`draft` → `ready_to_install` → `live` / `installation_error` / `paused`), duplicating, pausing/resuming, and safe deletion.
- **Engagement-Driven Analytics**: Track game plays, player session duration, widget views, click-through rates, and estimated rev-share.

---

## 🧭 Navigation & Information Architecture

The platform features a clean 5-tab navigation bar with a prominent global `+ Create widget` CTA:

1. **Home**: Overview metrics, setup checklist for first-time publishers, and recent widgets.
2. **Widgets**: Comprehensive widget repository with search, website filter, lifecycle status filter, and quick action controls.
3. **Analytics**: Outcome-focused engagement statistics and publisher optimisation recommendations.
4. **Websites**: Manage connected domains, publisher keys, and domain verification.
5. **Help**: Step-by-step installation guides for every CMS and a troubleshooting FAQ.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm or bun

### Local Development

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
```
